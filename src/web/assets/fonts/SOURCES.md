# Font sources

License: SIL Open Font License 1.1, see `IBM-Plex-LICENSE.txt` (`LICENSE.txt` of `@ibm/plex-sans` 2.0.0, identical in `@ibm/plex-mono` 2.5.0).

The `unicode-range` values in `src/web/styles/fonts.css` are copied from `css/ibm-plex-sans-default.css` and `css/ibm-plex-mono-default.css` of the same package versions.
